GitHub Portfolio Showcase

Type any GitHub username and see their public projects as a clean, shareable portfolio. No login, no token, no backend.

@

Try

  1. SearchEnter a GitHub username or paste a profile link.
  2. BrowseFilter by language or topic, search by keyword, sort by stars or recency.
  3. ShareCopy the address bar: ?user=octocat opens the same portfolio for anyone.

Only public data is used. This site reads public information from GitHub's REST API directly in your browser. There is no login, no access token, no server and no tracking. Responses are cached on your device for 10 minutes.
